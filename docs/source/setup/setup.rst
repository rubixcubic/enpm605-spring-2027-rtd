====================================================
Setup
====================================================

This section lists the software used throughout the course. Step-by-step
instructions are posted before the first lecture.

- **Ubuntu**: Ubuntu Desktop 24.04 LTS (Noble Numbat).
- **Python development**: VS Code and uv. Complete before the
  first lecture.
- **ROS 2**: ROS 2 Jazzy Jalisco and Gazebo Harmonic. Needed starting
  in Lecture 8 (March 30).

Minimum Hardware
----------------

.. list-table::
   :header-rows: 1
   :widths: 30 70
   :class: compact-table

   * - Component
     - Minimum
   * - CPU
     - Intel i5 or equivalent, 4 or more cores
   * - RAM
     - 16 GB (32 GB recommended)
   * - Storage
     - 50 GB free
