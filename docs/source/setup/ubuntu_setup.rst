====================================================
Ubuntu
====================================================

.. _setup-ubuntu:

The course uses **Ubuntu Desktop 24.04 LTS (Noble Numbat)**. ROS 2
Jazzy, the ROS version this course uses, is built for this release.

- Download: `Ubuntu Desktop <https://ubuntu.com/download/desktop>`_
- Installation guide:
  `Install Ubuntu Desktop <https://ubuntu.com/tutorials/install-ubuntu-desktop>`_

Use this course to learn Linux. You should know at least these shell
commands: ``ls``, ``pwd``, ``cd``, ``mv``, ``mkdir``, ``rm``,
``source``, ``touch``, ``man``, and ``grep``.

.. note::

   Detailed instructions, including dual boot, are posted before the
   first lecture.
