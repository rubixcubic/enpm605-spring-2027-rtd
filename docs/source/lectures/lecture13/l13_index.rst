Overview
--------

This lecture covers three tools for building robot applications that are
larger than one node: behavior trees for decisions, lifecycle nodes for
controlled startup, and bags for recording and replaying data.

Planned Topics
--------------

- Behavior tree concepts
- ``py_trees`` and ``py_trees_ros``
- The lifecycle node state machine
- Implementing a lifecycle node, and changing its state from code
- ROS 2 bags: storage formats, recording, inspecting, and replaying
- Foxglove
- Analyzing a recorded run with pandas
