Overview
--------

This lecture introduces ROS 2: what it is, how its parts talk to each
other, and how to write your first nodes in Python.

Planned Topics
--------------

- What ROS is
- ROS 2 architecture: monolithic versus distributed systems
- Core components and the Data Distribution Service (DDS)
- The publish/subscribe model
- Introspection tools
- Workspaces and packages
- Writing nodes in Python with ``rclpy``
