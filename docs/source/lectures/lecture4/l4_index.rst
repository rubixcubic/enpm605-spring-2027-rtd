Overview
--------

This lecture covers functions, from writing and calling them to passing
them around as values. It ends with callbacks, the pattern ROS 2 uses
for subscriptions and timers.

Planned Topics
--------------

- Defining and calling functions
- Arguments: positional, keyword, default, ``*args``, and ``**kwargs``
- Scopes
- Pass-by-assignment
- Type hints
- Recursive functions
- Functions as values: callables and first-class functions
- Lambda functions and closures
- Callbacks
- Partial functions with ``functools.partial``
