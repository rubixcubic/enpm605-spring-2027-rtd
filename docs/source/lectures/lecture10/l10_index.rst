Overview
--------

This lecture covers node parameters, your own message types, and the two
request-based ways nodes communicate: services and actions.

Planned Topics
--------------

- Declaring, retrieving, using, and setting parameters
- Custom interfaces: messages (``.msg``), services (``.srv``), and
  actions (``.action``)
- Writing a service server and a service client
- Writing an action server and an action client
