Overview
--------

This lecture covers how a robot describes where it is, how it drives,
and how ROS 2 keeps track of coordinate frames.

Planned Topics
--------------

- Pose: position and orientation, with quaternions
- Gazebo Harmonic and RViz2
- The differential drive model
- Odometry
- A proportional controller
- Coordinate frames
- TF2: broadcasting and listening to transforms
