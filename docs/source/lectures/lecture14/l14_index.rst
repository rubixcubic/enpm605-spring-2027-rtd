Overview
--------

This lecture is new for 2027. It shows where learned models fit in a ROS
2 system, and how to check what a model outputs before the robot acts on
it.

Planned Topics
--------------

- Where learned models fit in a ROS 2 system
- A perception node: a pretrained vision model on camera images
- Publishing detections as ROS 2 messages
- Language commands: a large language model that calls ROS 2 actions
- Checking model outputs before the robot acts
