Overview
--------

This lecture continues object-oriented programming with the features ROS
2 code relies on, such as inheritance from a base class, and the modern
tools for writing classes with less code.

Planned Topics
--------------

- Decorators
- Class methods and static methods
- Object relationships
- Inheritance
- Polymorphism
- Abstract base classes
- Data classes
- ``__slots__``
- Protocols
