====================================================
Lectures
====================================================

Overview
--------

The lectures in ENPM605 come in two parts. Lectures 1 to 7 teach the
Python language, with robotics examples. Lectures 8 to 14 use Python to
program mobile robots with ROS 2 Jazzy, in simulation with Gazebo
Harmonic. Lecture materials are available on Canvas.

.. note::

   The lecture plan for Spring 2027 is **tentative**. Each lecture's page
   lists its planned topics until its slides are ready.


Lecture Organization
--------------------

Each lecture page contains the following sections:

.. grid:: 1 2 2 2
    :gutter: 3

    .. grid-item-card:: Lecture
        :class-card: sd-border-info

        The main lecture content, adapted from the in-class slides.
        Covers definitions, explanations, code examples, and
        demonstrations for the topic.

    .. grid-item-card:: Python Exercises
        :class-card: sd-border-info

        Programming exercises for the lecture topic. You practice the
        concepts from the lecture by writing and running code.

    .. grid-item-card:: Quiz
        :class-card: sd-border-info

        Multiple choice, true/false, and short-answer questions about
        the lecture. Answers are hidden behind dropdowns, so you can
        check yourself.

    .. grid-item-card:: References
        :class-card: sd-border-info

        Links to official documentation, tutorials, and recommended
        reading for the lecture topic.
