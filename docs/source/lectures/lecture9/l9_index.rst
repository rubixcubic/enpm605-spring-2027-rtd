Overview
--------

This lecture covers how to start and configure many nodes at once, and
how ROS 2 runs their callbacks.

Planned Topics
--------------

- Python launch files
- Launch arguments, conditions, groups, and includes
- Namespaces
- Remapping nodes, topics, and parameters
- Single-threaded and multi-threaded executors
- Callback groups: mutually exclusive and reentrant
