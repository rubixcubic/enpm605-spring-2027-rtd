Overview
--------

This lecture introduces the course and sets up the tools you use all
semester: VS Code, Docker containers, and a Python linter. It ends with
how Python runs a program and a first look at variables.

Planned Topics
--------------

- Course structure, grading, and policies
- Software and hardware: Ubuntu 24.04, Docker, VS Code, ROS 2 Jazzy, and
  Gazebo Harmonic
- Developing inside a container with VS Code Dev Containers
- Running Python in VS Code
- Linting and formatting Python code
- Verifying your environment
- The Python execution pipeline
- Introduction to Python variables
